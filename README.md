# Online Courses Power BI Analysis

## Project Overview

A Power BI analysis of an online courses dataset, exploring pricing, course performance, and learner engagement.

This project was completed as part of an online Power BI course.

## Key Analysis

* Course performance across subjects and levels
* Pricing and subscriber patterns
* Free vs. paid courses
* Subscribers, reviews, and lectures
* Top-performing courses

## Key Insights

* Free courses represent 8.42% of the catalog but attract 30.4% of total subscribers.
* Web Development leads in subscribers with approximately 2.7M.
* Web Development also has the highest average course price at $77.
* Most courses fall within the $1–$50 price range.

## Tools

* Power BI
* Power Query
* DAX
* Data Visualization

## Dashboard

Interactive Power BI dashboard designed to explore online course performance, pricing, and learner engagement.
